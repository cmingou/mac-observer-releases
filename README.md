# Mac Observer releases

Update feed and downloads for [Mac Observer](https://github.com/cmingou/mac-observer)
(private source). Nothing here is hand-edited: `scripts/release.sh` in the
source repo publishes each version.

- `appcast.xml` — the Sparkle feed the app polls.
- Releases — one per version, each with the notarized `MacObserver-x.y.z.dmg`.
